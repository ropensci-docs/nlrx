# Simulated Annealing call simulations function

Simulated Annealing call simulations function

## Usage

``` r
util_run_nl_dyn_GenSA(nl, seed, threads = 1, nreplicates = 1, ...)
```

## Arguments

- nl:

  nl object

- seed:

  current model seed

- threads:

  number of NetLogo threads used for execution (handled via NetLogo).

- nreplicates:

  number of replicated model runs per evaluation
