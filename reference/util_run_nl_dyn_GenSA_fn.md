# Simulated Annealing run simulation function

Simulated Annealing run simulation function

## Usage

``` r
util_run_nl_dyn_GenSA_fn(param, nl, evalcrit, seed, threads = 1, ...)
```

## Arguments

- param:

  vector of model parameters, generated by GenSA function

- nl:

  nl object

- evalcrit:

  evaluation criterion for simulated annealing

- seed:

  vector of model seeds, one per replicated run of this evaluation

- threads:

  number of NetLogo threads used for execution (handled via NetLogo).
